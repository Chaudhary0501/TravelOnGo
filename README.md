# 🧳 TravelOnGo

A clean, responsive travel accommodation booking platform inspired by Airbnb.

## ✨ Features
- 🏨 Browse listings with images & details  
- 🗺 Map preview for each stay  
- 🔐 JWT-based login & signup  
- ⚙️ Fast backend with optimized MongoDB queries  
- 📱 Fully responsive UI with Bootstrap  

## 🛠 Tech Stack
- **Backend:** Node.js, Express.js  
- **Frontend:** HTML, CSS, Bootstrap  
- **Database:** MongoDB  
- **Auth:** JWT  

## 🌍 Live Demo
🔗 https://travelongo-where-luxury-meets-paradise.onrender.com

## ▶️ Run Locally
- git clone https://github.com/Chaudhary0501/TravelOnGo
- cd TravelOnGo
- npm install
- npm start
